# vigo-admin

Trang quản trị Vigo (Next.js 15, static export) — một bản build phục vụ 4 cổng: admin., htx., kol., daily.vigogroup.vn (Cloudflare Pages).

- Chạy local: `npm ci` rồi `npm run dev` (cổng 9002).
- Kiểm: `npm run typecheck`, `npm test`, `npm run test:pages`.
- `npm run build` chỉ build, KHÔNG deploy.
- Deploy DEV/PROD: [docs/DEPLOY.md](docs/DEPLOY.md). Luật cho AI/agent: [AGENTS.md](AGENTS.md). Hướng dẫn làm việc: [CLAUDE.md](CLAUDE.md).
